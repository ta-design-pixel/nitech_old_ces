提出ファイルの説明
提出ファイルはFindFile1.javaである。本プログラムは、コマンドライン引数として指定された検索文字列と検索対象ファイルを受け取り、ファイル内から検索文字列を含む行を探索する。ファイルは BufferedReader を用いて1行ずつ読み込まれ、各行に対して indexOf() メソッドによる文字列検索を行う。検索文字列が含まれている場合は、その行の行番号と内容を表示する。また、ファイルが存在しない場合や読み込み時にエラーが発生した場合には例外処理によってエラーメッセージを表示する。

課題1
提出ファイルの説明
提出ファイルはFileCopy.javaである。本プログラムは、コマンドライン引数で指定されたコピー元ファイルの内容を読み込み、コピー先ファイルへ同じ内容を書き込むことでファイルの複製を行うプログラムである。
コピー処理では1024バイトの配列をバッファとして用意し、コピー元ファイルから読み込んだデータを順次コピー先ファイルへ書き込む。コピーが正常に完了すると、コピー元とコピー先のファイル名を表示して処理終了である。

プログラムの実行方法
ターミナルのkadai1の場所でjava FileCopy コピー元ファイル コピー先ファイルと入力すると実行される。

結果
javac FileCopy.java
java FileCopy sample_utf8.txt sample_utf8-copy.txt
sample_utf8.txt を sample_utf8-copy.txt にコピーしました。
diff sample_utf8.txt sample_utf8-copy.txt
java FileCopy sample_sjis.txt sample_sjis-copy.txt
sample_sjis.txt を sample_sjis-copy.txt にコピーしました。
diff sample_sjis.txt sample_sjis-copy.txt
java FileCopy sample.jpg sample-copy.jpg
sample.jpg を sample-copy.jpg にコピーしました。
diff sample.jpg sample-copy.jpg

考察
BufferedInputStream と BufferedOutputStream を利用しているため、1バイトごとに入出力を行う場合と比べて処理効率が向上し、大きなファイルのコピーも比較的高速に実行できることが分かった。入力ストリームと出力ストリームを閉じる処理が実装することが大切だとわかった。
