課題1
提出ファイルの説明
Graph.javaはグラフを表現するプログラムである。各頂点を Node クラス、各辺を Edge クラスで管理している。前回の課題から拡張し、各辺に重み（double型）を持たせた。入力ファイルを読み込み、隣接リスト形式でグラフを構築する機能を持つ。また、printGraph() メソッドにより、読み込んだグラフを「接続先@重み」の形式で表示する。
GraphTester.javaはGraph クラスをテストするためのプログラムである。コマンドライン引数で指定した入力ファイルを読み込み、printGraph() を実行してグラフの内容を表示する。

プログラムの実行方法
ターミナル上のkadai123/ディレクトリでmake kadai1と入力すると実行される。

結果
0:1@4.0,3@6.0,4@1.0
1:6@3.0
2:
3:6@2.0
4:5@2.0
5:3@1.0,2@5.0
6:2@1.0

考察
実行結果から、入力ファイルの内容が正しく読み込まれ、各辺の重みも含めて期待通りに表示されることを確認できた。今回の課題を通して、データ構造を拡張する方法や、オブジェクト指向を利用してプログラムの保守性・拡張性を高めることの重要性を学ぶことができた。

課題2
提出ファイルの説明
Dijkstra.javaはGraph クラスを継承し、ダイクストラ法による最短経路探索を実装したプログラムである。doDijkstra() メソッドでは、指定した始点から各頂点までの最短距離を計算し、最短経路木の親頂点を記録する。getShortestPath() メソッドでは、親頂点をたどることで、始点から終点までの最短経路を配列として返す。
DijkstraTester.javaはDijkstra クラスをテストするためのプログラムである。コマンドライン引数で指定したグラフファイルを読み込み、始点を0としてダイクストラ法を実行する。その後、各頂点までの最短経路を順番に表示し、到達できない頂点がある場合は「到達不能」と表示する。

プログラムの実行方法
ターミナル上のkadai123/ディレクトリでmake kadai2と入力すると実行される。

結果
始点 0 から各ノードへの最短経路:
end = 0: 0
end = 1: 0, 1
end = 2: 0, 4, 5, 3, 6, 2
end = 3: 0, 4, 5, 3
end = 4: 0, 4
end = 5: 0, 4, 5
end = 6: 0, 4, 5, 3, 6

考察
今回の課題では、重み付きグラフに対してダイクストラ法を実装し、始点から各頂点までの最短経路を求めるプログラムを作成した。各頂点までの最短距離を管理し、未訪問頂点の中から最も距離の短い頂点を順番に選択して距離を更新することで、最短経路を求めている。また、距離を更新する際に親頂点を記録することで、計算後に始点から終点までの経路を復元できるようにした。

課題3
提出ファイルの説明
PQDijkstra.javaはDijkstra クラスを継承し、優先度付きキュー（PriorityQueue）を用いたダイクストラ法を実装したプログラムである。doDijkstra() メソッドをオーバーライドし、探索対象の頂点を優先度付きキューで管理することで、効率的に最短経路を探索する。最短距離が更新された場合には親頂点を記録し、最短経路木を構築する。
PQDijkstraTester.javaはPQDijkstra クラスをテストするためのプログラムである。コマンドライン引数で指定したグラフファイルを読み込み、始点を0として優先度付きキュー版ダイクストラ法を実行する。その後、各頂点までの最短経路を順番に表示し、到達できない頂点がある場合は「到達不能」と表示する。

プログラムの実行方法
ターミナル上のkadai123/ディレクトリでmake kadai3と入力すると実行される。

結果
PQ使用: 始点 0 からの最短経路木:
end = 0: 0
end = 1: 0, 1
end = 2: 0, 4, 5, 3, 6, 2
end = 3: 0, 4, 5, 3
end = 4: 0, 4
end = 5: 0, 4, 5
end = 6: 0, 4, 5, 3, 6

考察
今回の課題では、通常のダイクストラ法を改良し、優先度付きキュー（PriorityQueue）を利用した実装を行った。探索対象の頂点を優先度付きキューで管理することで、毎回全頂点を探索して最小距離の頂点を探す必要がなくなり、より効率的に最短経路を求めることができる。

自己評価
A
