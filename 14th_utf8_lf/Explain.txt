課題3
提出ファイルの説明
WUGraph.javaは前述したとおりである。
UnionFind.javaは互いに素な集合を管理する Union-Find データ構造を実装したプログラムである。find() メソッドでは、指定した要素が属する集合の代表元（根）を返し、経路圧縮によって探索を高速化している。unite() メソッドでは、2つの集合を統合し、ランク（木の高さ）を用いることで木が深くなりすぎないようにしている。また、すでに同じ集合に属している場合は false を返し、それ以外の場合は集合を統合して true を返す。
UnionFindTester.javaはUnionFind クラスをテストするためのプログラムである。初期状態で各要素の代表元を表示した後、unite() メソッドを用いて集合を統合し、その後の find() の結果を表示する。さらに、すでに同じ集合に属する要素と異なる集合に属する要素に対して unite() を実行し、戻り値を確認することで、find() と unite() の動作を検証する。

プログラムの実行方法
ターミナル上のkadai123/ディレクトリでmake kadai3と入力すると実行される。

結果
初期状態

1 -> 1

union 0,1
union 1,2

find結果
0 -> 0
1 -> 0
2 -> 0

同じ集合か確認
false
true

考察
実行結果から、unite() によって集合が正しく統合され、find() を実行すると同じ集合に属する要素が同じ代表元を返すことを確認できた。また、既に同じ集合に属する要素に対して unite() を実行した場合には false が返り、異なる集合を統合する場合には true が返ることも確認できた。
Union-Find は集合の統合と判定を高速に行えるデータ構造であり、クラスカル法による最小全域木の構築では閉路が発生するかどうかを判定するために利用される。経路圧縮とランク併合を組み合わせることで、非常に高速に処理を行えることを学ぶことができた。
